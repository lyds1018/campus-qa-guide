## 1 链路

一次入库固定四步，失败在对应步骤停下并记录原因。

```text
扫描 → 解析 → 切分 → 入库（原件 + 解析结果 + 块 + 状态）
```

| 步骤 | 动作 | 失败处理 |
| --- | --- | --- |
| 扫描 | 按后缀收集文件，`doc_type` 取目录名或上传表单 | 不支持的格式跳过 |
| 解析 | 按扩展名分发解析器，得到页与块 | 正文少于 50 字判失败 |
| 切分 | 标题入 `section_path`，正文按句打包 | 产不出块判失败 |
| 入库 | 文档与块写在同一事务 | 整体回滚，原件对象保留 |

支持格式：`.pdf` `.md` `.markdown` `.txt` `.html` `.htm`。

## 2 解析

解析结果统一为 `pages[{no, text, blocks[{text, level}]}]`，落 MinIO 的 `parsed/{doc_id}/v{version}.json`，可回溯。

| 格式 | 解析方式 | 标题识别 |
| --- | --- | --- |
| PDF | PyMuPDF 逐页取文本与 spans | 字号大于正文且加粗 |
| Markdown | 按 ATX / Setext 标题切块 | `#` 层级，最多 3 级 |
| HTML | 标准库解析，块级标签分段 | `h1`–`h6` |
| TXT | 按空行分段 | 无标题，全部 `level=0` |

`level` 为 0 表示正文，1–3 表示标题层级。

## 3 切分

| 规则 | 口径 |
| --- | --- |
| 段落合并 | 标题只更新 `section_path` 并与后续正文合成一段，不单独成块 |
| 长段拆分 | 先按句末标点（`。！？；`）打包至 ≤500 字，单句超长再硬切 |
| 重叠 | 取上一块尾部 80 字内的完整句子作为下一块开头，找不到句界则不重叠 |
| 短块合并 | 不足 120 字的块并入前一块 |
| 分词 | jieba 搜索模式，空格拼接写入 `search_text` |

产物：`{ordinal, content, search_text, meta{section_path, page, char_len}}`。

参数：`CHUNK_SIZE=500`、`CHUNK_OVERLAP=80`、最短块 120 字。

## 4 幂等与版本

| 场景 | 行为 |
| --- | --- |
| 内容完全相同 | checksum 命中，任务记 `skipped`，不写库 |
| 同标题同类型、内容不同 | `version + 1`，新建一行文档 |
| 不同标题 | 各自独立文档，版本从 1 开始 |

标题取文件名去掉数字序号前缀；`effective_from` 从正文首个 `自 YYYY 年 M 月 D 日起` 或 `YYYY-MM-DD` 抽取。

## 5 队列与 worker

| 组件 | 职责 |
| --- | --- |
| `ingest_jobs` | 唯一事实源，存状态、阶段、错误 |
| Redis List `queue:ingest` | 只投 job_id |
| worker | `BRPOP` 取任务，同步执行，异常一律落 `failed` |

worker 启动做两件事：把超 30 分钟仍 `running` 的任务重置为 `pending`；队列为空时把 PG 里 `pending` 的任务补投进队列。

## 6 发布与回滚

| 动作 | 结果 |
| --- | --- |
| 草稿入库 | 新文档为 `draft`，**不归档**在版版本，旧版继续在线 |
| 发布 | 同标题同类型旧版置 `archived`，目标文档置 `published`，写 `published_at` |
| 回滚 | 把目标历史版本重新置 `published`，当前在版版本置 `archived` |

发布与回滚成功后清 `gw:kb:fingerprint` 与 `qa:terms`，答案缓存按新指纹自然失效。

## 7 向量回填

| 项 | 口径 |
| --- | --- |
| 触发 | `backfill_embeddings` 命令、运营接口 `POST /api/ops/documents/{id}/embed` |
| 范围 | `embedding IS NULL` 的块，可按文档过滤 |
| 批量 | 运营接口按 32 块一批提交，网关内部再按 64 条一次请求 |
| 失败 | 该批记 `ai_calls`，块保持 null，检索时该块只参与全文召回 |

## 8 命令

| 命令 | 用途 |
| --- | --- |
| `ingest <path> [--sync] [--publish] [--dry-run]` | 导入目录或单文件 |
| `worker [--once]` | 消费任务队列 |
| `backfill_embeddings [--force] [--limit N]` | 回填块向量 |
| `seed_terms [csv]` | 导入别名词典 |
| `seed_matters [--dry-run]` | 从已发布指南生成事项与流程 |
