## 1 页面

三个页面，路由懒加载。

| 路径 | 页面 | 内容 |
| --- | --- | --- |
| `/chat` | `Chat.vue` | 三栏问答工作台 |
| `/admin` | `Admin.vue` | 知识运营后台，五段导航 |
| `/health` | `Home.vue` | 依赖探活与版本信息 |

`/` 重定向到 `/chat`。页头固定深绿，左侧三个入口：问答、知识运营、系统状态。

## 2 问答页布局

| 栏 | 宽度 | 内容 |
| --- | --- | --- |
| 左 | 248px | 会话列表、新建对话、身份切换 |
| 中 | 自适应 | 消息流、输入框、示例问题 |

| ≤560px | 输入区与操作按钮换行堆叠 |

## 3 流式消费

用 `fetch` 读 `text/event-stream`，不使用 `EventSource`（需要 POST 与自定义头）。

| 环节 | 做法 |
| --- | --- |
| 发请求 | `POST /api/chat/stream`，带 `X-Demo-Token` |
| 读流 | `ReadableStream` 逐块解码，按空行切帧，取 `event:` 与 `data:` |
| 追加 | `delta` 事件追加到当前消息；`notice` 收进提示列表 |
| 收尾 | `answer` 事件拿整份结果，替换累积文本；`done` 结束加载态 |
| 中断 | 用户点停止即 `AbortController.abort()`，已收内容保留 |

当前消息体必须是响应式对象（`reactive`），否则流式追加后依据面板不刷新。

## 4 依据与清单

| 区域 | 行为 |
| --- | --- |
| 引用列表 | 点某条引用跳到对应原文块，标注所属段落 |
| 原文块 | 显示标题、小节、页码、相似度与来源（向量 / 全文 / 两者） |
| 清单 | 按材料、步骤、条件分组，可勾选，显示条数与进度 |
| 导出 | 勾选项提交 `/api/chat/export`，返回 CSV |
| 提示 | 降级、部分失败、口径冲突逐条列出 |

拒答时右栏改为显示可核对来源与拒答原因，不留空白。

## 5 消息流

| 元素 | 说明 |
| --- | --- |
| 用户气泡 | 右对齐，纯文本 |
| 回答气泡 | 左对齐，宋体正文，引用编号可点 |
| 阶段提示 | 理解中、检索中、生成中，随 `stage` 事件切换 |
| 反馈 | 每条回答下方「有用 / 没用」，选没用时弹原因表单 |
| 多段回答 | 按 `①②③` 分段，每段独立引用 |

## 6 运营页

五段导航，切段保留各自状态（`KeepAlive`）。

| 段 | 组件 | 内容 |
| --- | --- | --- |
| 入库与任务 | `UploadTab` | 上传、类型选择、任务列表、重试 |
| 审核与版本 | `ReviewTab` | 待审草稿、冲突提示、发布、回滚、补向量 |
| 事项与词典 | `CatalogTab` | 事项编辑、别名词典增删 |
| 看板与模型 | `MonitorTab` | 文档/块/队列计数、问答量与分位、槽位配置 |
| 评测与反馈 | `MetricsTab` | 回归档案、学生反馈列表 |

导航右侧显示当前序号 `01 / 05`，`?tab=` 可深链到指定段。

## 7 身份与深链

| 项 | 做法 |
| --- | --- |
| 身份 | `localStorage` 存 token，请求头带 `X-Demo-Token` |
| 切换身份 | 页头下拉，切换后整页重新挂载，避免残留上一位用户的数据 |
| 换身份入站 | `?token=admin-demo` 直接进入管理员视图 |
| 会话深链 | `?c=<conversation_id>` 打开指定会话，刷新不丢 |

## 8 视觉规范

| 项 | 值 |
| --- | --- |
| 底色 | 暖纸 `#f4f1ea`，卡片 `#fbfaf6` / `#ffffff` |
| 文字 | 墨 `#1b1a16`，次级 `#504c43`，弱化 `#7b756a` |
| 主色 | 深绿 `#243b34`，悬停 `#182c26` |
| 强调 | 赭 `#a9502d`，仅用于警示与拒答标记 |
| 语义 | 成功 `#3d6653`，警告 `#8d652d`，危险 `#9d4338` |
| 字体 | 标题衬线（思源宋体），正文无衬线（Inter / 思源黑体） |
| 圆角 | 12px，阴影极轻 |

不用渐变、不用发光、不用 emoji 作图标，图标统一走 `AppIcon.vue` 的内联 SVG。

Element Plus 主题通过覆盖 `--el-*` 变量接入同一套色板，不逐个组件改样式。
