## 1 表清单

13 张业务表，分四组。全部使用 `snake_case` 表名，主键默认 BigAutoField，`conversations` 用 UUID。

| 组 | 表 | 职责 |
| --- | --- | --- |
| 知识资产 | `documents` `chunks` `matters` `flows` `terms` `ingest_jobs` | 原件、检索单元、事项、流程、词典、入库任务 |
| 会话 | `conversations` `messages` | 会话主表、逐轮留痕 |
| 模型调用 | `ai_calls` `model_settings` | 调用台账、槽位覆盖 |
| 接入与评测 | `api_logs` `feedback` `eval_runs` | 访问审计、学生反馈、回归档案 |

## 2 知识资产

### 2.1 documents

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| title | varchar(200) | 文件名去序号前缀得到 |
| doc_type | varchar(16) | `guide` / `policy` / `faq` / `notice` |
| dept | varchar(80) | 可空 |
| source_path | varchar(300) | 语料内相对路径 |
| object_key | varchar(300) | MinIO 原件键 |
| checksum | varchar(64) | 唯一，SHA-256，幂等依据 |
| mime / size / page_count | — | 解析结果回填 |
| status | varchar(16) | `draft` / `published` / `archived` |
| version | int | 同标题同类型递增 |
| effective_from / effective_to | date | 正文抽取的施行日期 |
| published_at | datetime | 发布时写入 |

索引：`(status, doc_type)`、`(title, doc_type, version)`。

### 2.2 chunks

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| document | FK | 级联删除 |
| ordinal | int | 与 document 联合唯一 |
| content | text | 原文片段，≤ CHUNK_SIZE |
| search_text | text | jieba 搜索模式分词，空格拼接 |
| meta | json | `section_path` / `page` / `char_len` |
| embedding | vector(1024) | 可空，未回填时为 null |
| status | varchar(16) | 随文档同步 |

### 2.3 matters / flows / terms

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| matters | code（唯一）、name、dept、category、audience、location、contact、status、version、effective_* | 事项主表 |
| flows | matter（FK）、step_no（与 matter 联合唯一）、title、description、materials（JSON）、channel、duration_hint | 事项下的步骤链 |
| terms | term、canonical、term_type（`alias`/`abbr`/`synonym`）、weight | `(term, canonical)` 唯一 |

### 2.4 ingest_jobs

| 字段 | 说明 |
| --- | --- |
| source_path | 绝对路径，worker 直接读 |
| doc_type / dept / publish | 入库参数 |
| document | 成功后回填，`SET NULL` |
| status | `pending` / `running` / `succeeded` / `failed` / `skipped` |
| stage | `parse` / `chunk` / `persist` |
| message | 失败原因或块数 |
| started_at / finished_at | 执行时间 |

索引：`(status, created_at)`。

## 3 会话

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| conversations | id（UUID）、user_key、title、audience、turn_count、last_active_at | 首问前 60 字作标题 |
| messages | conversation（FK）、turn、role、content、intent、answerable、refusal_reason、trace_id、latency_ms、payload | `(conversation, turn, role)` 唯一 |

`messages.payload` 存整份 `TurnResult`：引用、证据、清单、提示、校验结果都在里面，回放不再反查能力层。

索引：`(conversation, turn)`、`(trace_id)`。

## 4 模型调用

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| ai_calls | trace_id（UUID）、task、provider（槽位名）、model、status、attempt、cached、stream、prompt_tokens、completion_tokens、latency_ms、first_token_ms、cost、error_code/msg、meta | 每次模型调用一行 |
| model_settings | slot（唯一）、base_url、model、enabled、note | 覆盖 `.env`，只存地址与模型名，不存密钥 |

`ai_calls.status`：`ok` / `degraded` / `failed` / `timeout` / `blocked`。失败类另有部分索引 `(created_at) WHERE status IN ('failed','timeout','blocked')`。

## 5 接入与评测

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| api_logs | trace_id、user_key、role、method、path、status、latency_ms、ip、bucket、limited、error | 只记元数据，不记问句与答案 |
| feedback | user_key、conversation_id、trace_id、question、answer_excerpt、rating、reason、expect、reviewed | `expect` 标应可答/应拒答 |
| eval_runs | kind（`eval`/`drill`）、label、samples、metrics（JSON）、report_path、cost、duration_ms、started_at/finished_at | 每次跑批或演练一行 |

## 6 索引

| 索引 | 类型 | 用途 |
| --- | --- | --- |
| `idx_chunk_search_text_gin` | GIN on `to_tsvector('simple', search_text)` | 中文全文召回 |
| `idx_chunk_embedding_hnsw` | HNSW `vector_cosine_ops`，仅 `embedding IS NOT NULL` | 向量召回 |
| `idx_term_term_trgm` | GIN `gin_trgm_ops` | 别名模糊匹配 |

三个都是表达式或部分索引，用 `RunSQL` 显式创建。

## 7 状态机

**文档与块**：`draft → published → archived`。同标题同类型发布新版本时，旧版置 `archived`；块的 `status` 始终跟随所属文档。

**入库任务**：`pending → running → succeeded | failed | skipped`。`skipped` 表示 checksum 已存在。

## 8 Redis 键

| 键 | 内容 | TTL |
| --- | --- | --- |
| `orc:sess:{conversation_id}` | 上下文窗口、槽位、上一轮事项与意图 | 1800s |
| `queue:ingest` | 待处理 job_id 列表 | 无 |
| `gw:cache:l1:{model}:{hash}` | chat 结果，hash 含知识指纹 | 86400s（降级 600s） |
| `gw:cache:l2:{model}:{hash}` | 文本向量 | 2592000s |
| `gw:cache:l3:{model}:{hash}` | 重排结果 | 604800s |
| `gw:kb:fingerprint` | 在版文档数 + 最新发布时间 | 60s |
| `qa:terms` | 别名到规范名的映射 | 300s |
| `acc:rl:{bucket}:{user}:{window}` | 固定窗口计数 | 70s |
| `gw:cb:{slot}:{fail\|open\|tripped\|ok\|probe}` | 熔断的失败计数、打开标记、恢复试探 | 窗口或冷却时长 |
| `gw:fault:{slot}` | 故障注入开关 | 300s |
| `gw:budget:{date}` | 当日已花费用（微元整型） | 30 小时 |
| `gw:model:overrides` | 槽位覆盖表快照 | 30s |
