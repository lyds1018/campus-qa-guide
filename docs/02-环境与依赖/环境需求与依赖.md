## 3 前端依赖

Node 20 LTS，pnpm 管理，锁文件 `pnpm-lock.yaml`。

### 3.1 运行

| 包                       | 版本     | 用途                  |
| ----------------------- | ------ | ------------------- |
| vue        | 3.5.x | 框架 |
| vue-router | 4.5.x | 路由（`/chat`、`/admin`、`/health`） |
| element-plus | 2.9.x | 桌面端组件库（表格、表单、抽屉、树） |
| axios      | 1.7.x | 普通接口（SSE 走原生 fetch） |

学生端与管理后台都是 Vue 页面；Django Admin 只用于查看表与模型调用记录。图标是自绘的线性 SVG（`components/AppIcon.vue`），不引图标包。

`package.json` 里另锁着 pinia、markdown-it、dompurify、@element-plus/icons-vue 四个当前代码未引用的包。按"不用就不写进本表"的约定不列，下次整理依赖时一并移除。

| vite | 6.0.x | 构建、开发代理 |

| vue-tsc | 2.2.x | 构建前类型检查 |
